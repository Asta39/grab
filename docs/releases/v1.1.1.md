## What's new

- **What's new tour:** after updating, a short illustrated tour of the new features. Find it again any time in Settings → Help
- **Report a problem:** describe what went wrong and, if you like, attach diagnostics (Grab version, system and recent errors, never your files). It opens a ready-made GitHub issue, or copies the report if you don't use GitHub
- **Suggest a feature:** share an idea for Grab the same way
- **Back up your progress:** save your Grab Club level, badges, streak and looks to a file, and restore it on a new phone
- **GIFs and stickers on Mac and Windows:** the clip maker now works on computers too
- **Support Grab:** a once-a-day card and a banner in Settings, if you'd like to buy me a soda
- Update notes inside Grab are now nicely formatted

## Fixes

- Grab now remembers crashes, so they can be included in a problem report
- The Wrapped buttons use Grab's font
