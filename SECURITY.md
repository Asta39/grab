# Security Policy

## Supported versions

Only the [latest release](https://github.com/Asta39/grab/releases/latest) receives security fixes. Grab updates itself from inside the app, so please stay on the newest version.

## Reporting a vulnerability

Please **don't** open a public issue for security problems.

Report it privately through GitHub instead: go to the [Security tab](https://github.com/Asta39/grab/security) and choose **Report a vulnerability**. Include:

- what the problem is and what an attacker could do with it
- steps to reproduce, or a proof of concept
- the Grab version and platform (Android, Windows or macOS)

You'll get a reply within a week. Once a fix is released, you'll be credited in the release notes unless you'd rather stay anonymous.

## Scope

In scope: the Grab apps, the update mechanism, how Grab stores files and history, and the website.

Out of scope: bugs in sites Grab downloads from, and problems in yt-dlp or FFmpeg themselves (please report those [to yt-dlp](https://github.com/yt-dlp/yt-dlp/security) or [to FFmpeg](https://ffmpeg.org/security.html)).
